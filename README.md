## 学习时间线

- **Day 1** 指针基础 —— 指针是存地址的变量，`arr[i]` 等价于 `*(arr+i)`
- **Day 2** 指针与函数 —— 改形参无效，改指针指向的内容有效；要改指针本身需要 `int **`
- **Day 3** 字符串 —— `char[]` 可写、字符串字面量只读；`%s` 是「给个地址，一直走到 `\0`」
- **Day 3.5** 结构体 —— 变量用 `.`，指针用 `->`；自引用必须写 `struct Node *`
- **Day 4** 动态内存 —— 容量翻倍是均摊 O(1)，每次 +1 是 O(n²)

## 编译方式

```bash
gcc -std=c11 -Wall -Wextra 文件名.c -o 输出名
```

## 踩过的坑

1. **往字符串常量里写** —— `char *s = "hello"; s[0] = 'H';` 直接崩溃。写入目标必须指向数组或 `malloc` 出来的内存。
2. **`while (ch = getchar() != EOF)`** —— 少了括号，`ch` 会被赋成 0/1。要写 `while ((ch = getchar()) != EOF)`。
3. **`realloc` 失败** —— 不能写 `p = realloc(p, ...)`，失败时原指针丢失。要用临时变量接返回值。
4. **结构体数组排序** —— 交换 `x` 时忘了同时交换 `y`，数据就错位了。用结构体 + `qsort` 可以避免。
5. **双层循环超时** —— 查找类问题 O(n×m) 会 TLE，改成「排序 + 二分」。
6. **`char *pp = &p;`（p 是结构体）** —— 类型不匹配，应该是 `Point *pp = &p;`。
7. **一次循环读两次 `getchar()`** —— 会丢掉一半字符。一个循环只能读一次。
